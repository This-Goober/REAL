# Skills

Two generations of the pipeline. **[`batch-1/`](./batch-1/)** is the
field-tested first generation and the home of the
[Workflow Gap Report](./batch-1/GAP-REPORT.md) — the verified findings.
**[`batch-2/`](./batch-2/)** is the rebuild derived from those findings
(regression-tested; field testing in progress). Each batch folder explains
itself; each skill folder inside is installable as-is (zip it → upload to
Claude → Settings → Capabilities → Skills).
